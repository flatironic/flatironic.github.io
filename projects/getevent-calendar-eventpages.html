GetEvent Calendar Event Pages

The core pages of the GetEvent website were the event pages, which carried all the information for an event.

Built with Bootstrap and a focus on responsive design, these pages emphasized SEO-centric markup while providing a customizable interface for event directors. Registration details, event information, Google Maps integration, a photo gallery, past event details, participant reviews and supporting features such as results and an event director profile were all included.

At its peak, before the site wound down in the summer of 2015, thousands of event pages let hundreds of event directors customize and create a web presence for their events.
