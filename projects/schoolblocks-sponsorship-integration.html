SchoolBlocks Sponsorship Integration

Sponsorship provided subtle advertising opportunities on school websites that sponsors could manage themselves.

The system to approve sponsors and create or modify their sponsorship details had to be built. Inline editing was the established style of the site, but the existing implementation needed upgrading, which made this a good opportunity to introduce a comprehensive inline editing solution.

Sponsors created an account during checkout and built a sponsorship "card" using Bootstrap, the Google Maps API and the X-Editable JavaScript library. I built a JavaScript module that provided a seamless inline editing experience for managing those cards over AJAX. The cards were surfaced through ads, listings, and both the SchoolBlocks and school district control panels.
