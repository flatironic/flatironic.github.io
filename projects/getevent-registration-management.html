GetEvent Registration Management

GetEvent was an endurance sport calendar and registration site. The registration system was a custom e-commerce application that collected participant information defined by event directors as part of the checkout process.

Event directors relied on the site to manage the participants in their events, so tools to manage those participants and better reporting had to be built.

I added web-based reports and general functionality alongside a complete UI overhaul of the GetEvent site, previously PreRace.com. After adding an API, I built web-based reports in the event director dashboards and third-party JavaScript widgets that displayed rosters on event directors' own websites.

The site was built with Bootstrap and a JavaScript-driven interface over a RESTful API.

The result was a usable, responsive design that made it simple for event directors to get registration data quickly and change it if needed.
