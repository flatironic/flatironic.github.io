GetEvent Calendar Map View

A map version of the event calendar was a missing feature of GetEvent.

I built it against the RESTful event-search API using Bootstrap and a data-bound JavaScript client, chosen to handle the high degree of binding between the map and the event list. The list repopulated when the user interacted with the map, unless they turned that behavior off. Geolocation, a customized Google map, event filtering and a responsive design made the tool highly usable.

The success of the map view prompted an alternative version for event sales, which let event directors list their events for sale through the same application, with an event sales page included in the app.
