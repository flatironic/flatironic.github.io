Attendance Tracker Overview

The Attendance Tracker was used at live events to check registered attendees in and out. The number of hours attended set the number of CPE credits earned, with the ability to add details about each registrant. Any existing customer in the Western CPE database could be looked up and added as needed. The application had to support roll-call speed and responsiveness in low-bandwidth environments.

It was a Vue.js application built into a .NET admin website. The application never required a page refresh, and convenience of use was a primary focus. Modules for UI components and Excel exporting were added via Node.js packages to the Axios-based RESTful service layer.
