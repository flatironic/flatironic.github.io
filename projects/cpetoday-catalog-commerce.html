CPE Today — Catalog & Commerce

CPE Today is a continuing professional education provider for financial professionals, offering a course catalog, e-commerce and an e-learning system for accruing CPE credits.

I developed the website and single-page application primarily in Vue. The catalog carries advanced filtering across type, field of study, format and credit, over a result set of well over a hundred concurrent courses and events, with counts that update against the active filter set.

Alongside a conventional cart, I built a front-end checkout that allows a single course to be purchased directly from its own course page — removing the cart round-trip for the most common purchase, which is one course at a time.

I also folded a white-label solution into the build process, so the same codebase could be delivered as custom integrations for several different applications.
