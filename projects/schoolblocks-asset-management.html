SchoolBlocks Asset Management with Gulp

The SchoolBlocks application used a large number of JavaScript resources, and the performance cost of loading dozens of individual files was significant.

By using Gulp to manage project assets, I was able to combine and minify the JavaScript and SASS files as needed for different hosting environments. Gulp managed every asset, including font files, images, SASS and JavaScript.

Google Chrome profiling demonstrated a significant reduction in load and paint time while improving the development process.
